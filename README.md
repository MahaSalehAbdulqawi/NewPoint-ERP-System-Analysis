# NewPoint-ERP-System-Analysis
System Analysis and Design (SAD) project enhancing the NewPoint ERP system for Al-Nahdah Auto Parts Company (KAU - MIS377).

---

## 📌 About The Project
This project provides a System Analysis and Design (SAD) study to enhance the **NewPoint Accounting System** at **Al-Nahdah Auto Parts Company**.The main objective is to eliminate operational bottlenecks in the current workflow—such as manual inventory tracking, delayed purchasing cycles, and fragmented supplier communication—by introducingthrough process automation, integrated supplier communication, and compliance tracking.

---

## ⚡ Key Features
* **Automated Stock Alerts:** Automatic notification to suppliers when stock reaches reorder levels.
* **Supplier & Quote Dashboard:** Side-by-side comparison of supplier quotes and response tracking.
* **Order Tracking:** End-to-end purchasing workflow from request to delivery.
* **Analytics & Performance Reporting** Real-time visual inventory dashboards, Detailed supplier evaluation reports.

 ---

## 📐 System Models & Artifacts
* **Requirements:** Elicited via interviews, surveys, and financial documents.
* **Diagrams:** As-Is & To-Be Context Diagrams and DFD Level 0/1.
* **Agile Planning:** Product backlog prioritized using **MoSCoW** and Sprint 1 execution.
